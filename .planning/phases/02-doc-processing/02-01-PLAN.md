**006_match_documents_filtered.sql:**
```sql
-- Enhanced similarity search with metadata filtering
-- Filters by document_ids and subject_id BEFORE similarity ranking (RAG-05)
CREATE OR REPLACE FUNCTION match_documents_filtered(
  query_embedding vector(1024),
  filter_document_ids uuid[] DEFAULT NULL,
  filter_subject_id uuid DEFAULT NULL,
  match_threshold float DEFAULT 0.5,
  match_count int DEFAULT 5
)
RETURNS TABLE (
  id uuid,
  document_id uuid,
  content text,
  metadata jsonb,
  similarity float
)
LANGUAGE plpgsql
AS $$
BEGIN
  RETURN QUERY
  SELECT
    dc.id,
    dc.document_id,
    dc.content,
    dc.metadata,
    1 - (dc.embedding <=> query_embedding) AS similarity
  FROM document_chunks dc
  INNER JOIN documents d ON d.id = dc.document_id
  WHERE 1 - (dc.embedding <=> query_embedding) > match_threshold
    AND (filter_document_ids IS NULL OR dc.document_id = ANY(filter_document_ids))
    AND (filter_subject_id IS NULL OR d.subject_id = filter_subject_id)
    AND d.status = 'ready'
  ORDER BY dc.embedding <=> query_embedding
  LIMIT match_count;
END;
$$;
```

  <action>
Write tests first in `src/lib/ai/chunker.test.ts`, then implement in `src/lib/ai/chunker.ts`.

**Test file approach:**
- Import `chunkText` from `./chunker`
- No mocking needed — pure function, deterministic
- Create test text strings of known lengths for predictable assertions
- Verify chunk boundaries, overlaps, and sentence awareness

**Implementation:**
- Export `chunkText(text: string, options?: { readonly chunkSize?: number; readonly overlap?: number }): ReadonlyArray<TextChunk>`
- Default: chunkSize = 500, overlap = 50
- Algorithm:
  1. Normalize whitespace: replace `\r\n` with `\n`, collapse multiple spaces/newlines to single space, trim
  2. If normalized text is empty, return []
  3. If text length <= chunkSize, return single chunk (if >= 20 chars)
  4. Walk through text with pointer `start = 0`:
     a. Set `end = start + chunkSize`
     b. If `end >= text.length`, take remaining text as final chunk
     c. Otherwise, search backward from `end` for sentence boundary (`. `, `! `, `? `, `.\n`, `!\n`, `?\n`)
     d. If found within last 20% of chunk window, split there (after the punctuation)
     e. If no sentence boundary, search backward for word boundary (space)
     f. If no word boundary found, split at chunkSize exactly
     g. Create TextChunk with content and chunkIndex
     h. Advance start: `start = splitPoint - overlap` (overlap ensures context continuity)
  5. Filter out chunks with content.trim().length < 20
  6. Return readonly array of TextChunks

IMPORTANT: Use `import type` for TextChunk import. No `any` types. Pure function with no side effects.
