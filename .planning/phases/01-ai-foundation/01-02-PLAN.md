**Test file approach:**
- Mock global `fetch` using `vi.fn()`
- Create helpers to build mock non-streaming response and mock SSE streaming response
- For streaming tests: create a `ReadableStream` that yields SSE-formatted chunks (`data: {...}\n\n`)
- Use `vi.stubEnv()` for API key env vars

**Implementation:**
- Export `chatCompletion(options: ChatCompletionOptions): Promise<string | ReadableStream<string>>`
  - When `options.stream` is false/undefined: returns `string` (the assistant message content)
  - When `options.stream` is true: returns `ReadableStream<string>` that yields text content chunks
- Define two provider configs:
  - Primary: `{ name: 'openrouter', baseUrl: 'https://openrouter.ai/api/v1', apiKeyEnvVar: 'OPENROUTER_API_KEY', defaultModel: 'google/gemini-2.0-flash-exp:free' }`
  - Fallback: `{ name: 'nvidia-nim', baseUrl: 'https://integrate.api.nvidia.com/v1', apiKeyEnvVar: 'NVIDIA_NIM_API_KEY', defaultModel: 'meta/llama-3.1-8b-instruct' }`
- Internal `callLLMProvider(config, options)` function that makes the fetch call
- For non-streaming: parse JSON response, return `choices[0].message.content`
- For streaming: return a `TransformStream` that parses SSE lines (`data: {...}`) and yields `delta.content` strings. Handle `data: [DONE]` as end signal.
- Fallback logic: try primary → on failure → try fallback → on failure → throw
- Use `AbortSignal.timeout(30000)` for 30-second timeout (LLM responses are slower)
- OpenRouter requires `HTTP-Referer` and `X-Title` headers — set them to app URL/name

**IMPORTANT**: Use `import type` for type-only imports. The streaming transform must properly handle the SSE format: lines starting with `data: `, skipping empty lines and `[DONE]` signals.
