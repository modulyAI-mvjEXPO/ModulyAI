  <goal>
    Replace the mock `generateResponse()` in ExamMode.tsx with real AI-powered answers
    via a new `exam-solve` Netlify Function. Students paste a VTU PYQ question, select
    the mark value, and receive a structured, exam-ready answer grounded in their uploaded
    study materials and formatted per VTU marking scheme conventions.
  </goal>

  <steps>
    <step id="1">
      <title>Add ExamRequest and ExamResponse types to types.ts</title>
      <file>src/lib/ai/types.ts</file>
      <action>Append two new exported types at the end of the file</action>
      <details>
        ExamRequest: { question: string; mark: string; documentIds?: ReadonlyArray&lt;string&gt;; subjectId?: string; }
        ExamResponse: { answer: string; sources: ReadonlyArray&lt;{ documentId: string; content: string; similarity: number; }&gt;; }
        All fields readonly. No optional chaining needed — mark is always provided by UI.
      </details>
    </step>

    <step id="2">
      <title>Create netlify/functions/exam-solve.mts</title>
      <file>netlify/functions/exam-solve.mts</file>
      <action>Create new file modelled on chat.mts</action>
      <details>
        Reuse: createServerSupabaseClient, getEmbedding, chatCompletion, RagChunk, same HandlerEvent/HandlerResponse/CORS_HEADERS pattern.
        Import type ExamRequest from types.ts.
        Constants:
          - DEFAULT_MODEL = 'google/gemini-2.0-flash-exp:free'
          - RAG_MATCH_COUNT = 5, RAG_THRESHOLD = 0.5
          - MARK_INSTRUCTIONS for 2M/5M/10M/15M (exam-specific wording)
        buildExamSystemPrompt(chunks, mark, subjectId):
          - Base persona: "You are Moduly AI Exam Engine, a specialized answer-generation system for VTU students."
          - Task: "Generate a complete, exam-ready answer for the given previous year question."
          - Mark instruction from MARK_INSTRUCTIONS[mark]
          - VTU formatting rules in prompt: numbered steps, bold key terms, markdown only
          - Curriculum section from SUBJECT_PROFILES if subjectId provided (copy same SUBJECT_PROFILES from chat.mts)
          - Context section (same pattern as chat.mts)
        handler:
          - Validate POST method, parse body
          - Extract question (string), mark (string), documentIds, subjectId
          - getEmbedding(question)
          - supabase.rpc('match_documents_filtered', ...)
          - buildExamSystemPrompt(chunks, mark, subjectId)
          - chatCompletion({ model, messages: [systemMsg, userMsg], stream: false, temperature: 0.7, max_tokens: 3000 })
          - Return { answer: responseText, sources }
        No history param — exam answers are single-shot.
      </details>
    </step>

    <step id="3">
      <title>Add /exam-solve redirect to netlify.toml</title>
      <file>netlify.toml</file>
      <action>Append one [[redirects]] block</action>
      <details>
        from = "/exam-solve"
        to = "/.netlify/functions/exam-solve"
        status = 200
      </details>
    </step>

    <step id="4">
      <title>Wire ExamMode.tsx to real AI (replace mock)</title>
      <file>src/pages/ExamMode.tsx</file>
      <action>
        Remove generateResponse() function.
        Add solveWithAI() async function and buildAnswerHtml() helper.
        Replace setTimeout mock in sendMessage with real fetch.
        Add error state.
      </action>
      <details>
        REMOVE:
          - `function generateResponse(...)` (lines 24–96)

        ADD at top of file (after imports):
          - `import type { ExamRequest, ExamResponse } from '../lib/ai/types.ts';`

        ADD helper function buildAnswerHtml(markdown: string, mark: string): string:
          Returns HTML string:
          ```
          &lt;div class="em-ai-output"&gt;
            &lt;div class="em-solution-header"&gt;
              &lt;div class="em-solution-title-group"&gt;
                &lt;span class="em-solution-title"&gt;Solution Generated&lt;/span&gt;
              &lt;/div&gt;
              &lt;div class="em-marking-scheme"&gt;
                &lt;span&gt;Format: {mark}&lt;/span&gt;
              &lt;/div&gt;
            &lt;/div&gt;
            &lt;div class="em-markdown-body"&gt;{rendered markdown}&lt;/div&gt;
          &lt;/div&gt;
          ```
          Markdown rendering: simple regex replacements for **bold** → &lt;strong&gt;, ## heading → &lt;h4&gt;, numbered lists → &lt;ol&gt;&lt;li&gt;, bullet lists → &lt;ul&gt;&lt;li&gt;, newlines → &lt;br&gt;.
          (No external markdown library — keep bundle small, same approach as chat mock output.)
          Alternative: just set innerHTML directly to markdown string wrapped in em-markdown-body — CSS already handles h4/ul/p styling.

        ADD solveWithAI(question: string, mark: string): Promise&lt;string&gt;:
          Builds ExamRequest body, fetches '/exam-solve', parses ExamResponse, calls buildAnswerHtml(data.answer, mark).
          On error: returns a simple error HTML string wrapped in em-ai-output.

        MODIFY sendMessage:
          Remove setTimeout mock.
          Call setIsTyping(true), then await solveWithAI(text, selectedMark), then push AI message, setIsTyping(false).
          Use try/finally to ensure isTyping resets.
          Keep sendMessage as useCallback — needs to be async now.

        ADD error state:
          const [error, setError] = useState&lt;string | null&gt;(null);
          On fetch error: setError(message) and show as AI message (same approach as StudyMode).

        NOTE: Do NOT add progressive reveal — ExamMode is exam-answer mode, not conversational.
        Full answer appears at once (no typing animation needed for exam use case).
      </details>
    </step>
  </steps>
