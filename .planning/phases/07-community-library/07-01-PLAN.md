### Step 2: Add helper functions to Library.tsx

**File:** `src/pages/Library.tsx`

Add at top of file (before component):
- `inferDocType(title)` — keyword-based doc type inference → `'Notes' | 'PYQ' | 'Mind Map' | 'Other'`
- `getDocTypeColor(type)` → color string (violet/amber/rose/blue)
- `getDocTypeIcon(type)` → material icon string
- `getIconBgVar(type)` → 1|2|3|4 for CSS var
- `formatSize(bytes)` — reuse from UploadDocs pattern
- `formatDate(iso)` — reuse from UploadDocs pattern

These replace mock-data-derived display fields.

### Step 3: Rewrite Library component

**File:** `src/pages/Library.tsx`

Changes:
1. Add `import type { User } from '@supabase/supabase-js'`
2. Add `import { supabase } from '../lib/supabase'`
3. Add `import { useEffect } from 'react'` (already has `useState`, `useMemo`)
4. Add `import type { DocumentRow } from '../lib/ai/types'`
5. Replace `ALL_DOCS` mock with Supabase fetch in `useEffect`
6. Add state: `docs`, `loading`, `fetchError`, `removalPending` (Set of doc ids), `removalDone` (Set)
7. Component prop: `{ user: User }`
8. `fetchDocs`: `supabase.from('documents').select('id,title,file_type,file_size,created_at,user_id,status').eq('status','ready').order('created_at',{ascending:false})`
9. Replace `ALL_DOCS.filter(...)` `useMemo` with filtering over `docs` (DocumentRow[])
10. Derive display fields per-row: type via `inferDocType(doc.title)`, size via `formatSize`, date via `formatDate`, contributor = `"VTU Student"`
11. Replace mock `doc.type` / `doc.typeColor` / `doc.icon` / `doc.iconBgVar` / `doc.contributorColorVar` with derived values
12. Add loading/error/empty states in table body
13. "Request Removal" button: visible when `doc.user_id === user.id`, calls `requestRemoval(doc.id)`
14. `requestRemoval`: insert into `removal_requests`, add doc.id to `removalPending`/`removalDone` sets
15. Keep all existing filter/search/pagination logic (just swap data source)
