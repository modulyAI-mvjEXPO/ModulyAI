   ```typescript
   async function chatWithAI(
     message: string,
     documentIds: ReadonlyArray<string>,
     mark: string,
     strict: boolean,
     history: ReadonlyArray<{ role: 'user' | 'assistant'; content: string }>,
   ): Promise<ChatResponse> {
     const res = await fetch('/chat', {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({
         message,
         documentIds: documentIds.length > 0 ? documentIds : undefined,
         mark,
         strict,
         history: history.length > 0 ? history : undefined,
       }),
     });

     if (!res.ok) {
       const errBody = await res.json().catch(() => ({ error: 'Unknown error' }));
       throw new Error((errBody as Record<string, string>).error ?? `Chat failed (${res.status})`);
     }

     return res.json() as Promise<ChatResponse>;
   }
   ```

3. **Add a `buildHistory` helper** to convert messages to chat history format:
   ```typescript
   function buildHistory(msgs: ReadonlyArray<Message>): ReadonlyArray<{ role: 'user' | 'assistant'; content: string }> {
     return msgs
       .filter(m => m.role === 'user' || m.role === 'ai')
       .slice(-10)
       .map(m => ({
         role: m.role === 'ai' ? 'assistant' as const : 'user' as const,
         content: m.content,
       }));
   }
   ```
   Note: Maps 'ai' role to 'assistant' for the API, and caps at last 10 messages.

4. **Rewrite `sendMessage`** to use real API:

Add a client-side progressive text reveal effect so AI responses appear word-by-word, satisfying STUDY-02 (user sees text appearing progressively).

**Approach**: When a new AI message is added, its content is revealed progressively by rendering an increasing substring. A `revealedLength` state tracks how much of the last AI message has been shown. A `useEffect` with `requestAnimationFrame` or `setInterval` increments the revealed length word-by-word until the full content is shown.

**Changes to StudyMode.tsx:**

1. **Add state for progressive reveal**:
   ```typescript
   const [revealingId, setRevealingId] = useState<string | null>(null);
   const [revealedLen, setRevealedLen] = useState(0);
   ```

2. **Modify the sendMessage function** — after receiving the AI response and adding the message, trigger reveal:
   ```typescript
   // After setMessages(prev => [...prev, aiMsg]):
   setRevealingId(aiMsg.id);
   setRevealedLen(0);
   ```
   Also set `setIsTyping(false)` BEFORE starting reveal (typing dots stop, text starts appearing).

3. **Add a useEffect for the reveal animation**:
   ```typescript
   useEffect(() => {
     if (!revealingId) return;

     const msg = messages.find(m => m.id === revealingId);
     if (!msg) return;

     const fullLen = msg.content.length;
     if (revealedLen >= fullLen) {
       setRevealingId(null);
       return;
     }

     // Reveal ~3 characters per frame (adjustable for speed)
     const speed = 3;
     const timer = setTimeout(() => {
       setRevealedLen(prev => Math.min(prev + speed, fullLen));
     }, 12);

     return () => clearTimeout(timer);
   }, [revealingId, revealedLen, messages]);
   ```
   This creates a smooth typing effect at ~250 chars/second (3 chars every 12ms). Fast enough to not annoy, slow enough to look like streaming.

4. **Modify message rendering** to use revealed content:
   In the message map, when rendering an AI message's content:
   ```typescript
   const displayContent = (msg.id === revealingId)
     ? msg.content.slice(0, revealedLen)
     : msg.content;
   ```
   Use `displayContent` instead of `msg.content` in the `.split('\n').map(...)` rendering block.

5. **Add a blinking cursor** during reveal:
   When `msg.id === revealingId && revealedLen < msg.content.length`, append a blinking cursor span after the text:
   ```typescript
   {msg.id === revealingId && revealedLen < msg.content.length && (
     <span className="sm-cursor" />
   )}
   ```

6. **Disable input during reveal** (optional UX improvement):
   The textarea `disabled` prop should also check `!!revealingId`:
   ```typescript
   disabled={isTyping || !!revealingId}
   ```
   Same for the send button. This prevents sending while AI is "typing".
