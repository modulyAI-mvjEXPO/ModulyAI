# Plan 06-01: PYQ Intelligence — Topic Frequency Analysis

**Phase**: 6  
**Status**: Complete  
**Requirement**: EXAM-04

---

## Goal

Replace the static mock "Analysis Report" in ExamMode's left panel with a live backend-computed topic frequency analysis derived from uploaded PYQ documents.

---

## Acceptance Criteria

- [ ] `pyq-intelligence.mts` Netlify Function exists and returns `PyqIntelligenceResponse`
- [ ] Function identifies PYQ documents by title pattern from Supabase `documents` table
- [ ] Function applies keyword-rule engine across `document_chunks` content
- [ ] Function returns graceful fallback when no PYQ docs are found
- [ ] `ExamMode.tsx` left panel renders live topic cards and module weightage bars from API
- [ ] Both TypeScript configs compile clean

---

## Steps

### Step 1: Add PYQ intelligence types to `types.ts`

**Done when:** `PyqIntelligenceRequest`, `PyqTopicPattern`, `PyqModuleWeightage`, `PyqIntelligenceResponse` exported from `src/lib/ai/types.ts`

### Step 2: Create `netlify/functions/pyq-intelligence.mts`

**Done when:** Function handles POST, queries Supabase for PYQ docs + chunks, applies TOPIC_RULES, returns JSON with fallback

### Step 3: Add `/pyq-intelligence` route to `netlify.toml`

**Done when:** Redirect from `/pyq-intelligence` to `/.netlify/functions/pyq-intelligence` present

### Step 4: Wire ExamMode.tsx left panel to live analysis data

**Done when:** `fetchPyqIntelligence()` called on mount, patterns and moduleWeightage rendered via `.map()`, fallback on error

### Step 5: Run TypeScript checks

**Done when:** `npx tsc --noEmit` and `npx tsc -p tsconfig.functions.json --noEmit` both pass clean
