1 Backpropagation Algorithm Overview (4 Marks)

Backpropagation is a supervised learning algorithm used for training Multi-layer Perceptrons (Artificial Neural Networks). It works by computing the gradient of the loss function with respect to each weight by the chain rule, iterating backwards from the last layer to avoid redundant calculations of intermediate terms in the chain rule.

  • Forward Pass: Input is passed through the network to generate output.
  • Error Calculation: Difference between predicted output and actual target is calculated.
  • Backward Pass: Error is propagated back to update weights and reduce loss.

3 Vanishing Gradient Problem (4 Marks)

In deep networks with many layers using activation functions like Sigmoid or Tanh, gradients can become extremely small as they are backpropagated. This prevents weights in early layers from changing significantly, stalling the training process.

Solution: Use ReLU (Rectified Linear Unit) activation function which does not saturate for positive values.
